# 📝 Blog API App

A full-stack blog application built with Node.js, Express, EJS, and a REST API backend.  
The project demonstrates CRUD operations with a separated frontend and backend architecture.

---

## 🚀 Live Demo
https://blogit-app-1.onrender.com

---

## 📌 Features

- Create new blog posts
- Edit existing posts
- Delete posts
- View all posts in a dashboard layout
- REST API integration between frontend and backend
- Dynamic rendering using EJS templates

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- Axios
- Body-Parser
- HTML5
- CSS3
- JavaScript

---

## ⚙️ How It Works

- The **API server** handles all blog data (CRUD operations)
- The **client server** renders pages using EJS
- Axios is used to communicate between frontend and backend
- Posts are dynamically displayed and updated in real time
